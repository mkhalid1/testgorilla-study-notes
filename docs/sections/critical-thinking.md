# Critical thinking

**In one line:** you work out what must follow from given statements, spot hidden assumptions and weak reasoning, and order people or tasks from a set of clues.

TestGorilla lists its Critical Thinking test as a 12-minute test at **advanced** level, the hardest level among the cognitive tests in its library. It is not tied to one role. TestGorilla's examples include analysts, engineers, executives, lawyers, marketers and data scientists.

## What it measures

TestGorilla says the test covers:

- syllogism analysis
- drawing inferences
- spotting assumptions and fallacies
- evaluating the strength of arguments

It describes the questions as single or multiple-choice statements on topics that include syllogisms, sequences and arrangements, deduction, cause and effect, and reading comprehension.

That is a wide spread. The common thread is discipline: you answer from the information given, and you notice when an argument asks you to accept more than it has shown.

## How the questions look

| Type | What you get | What you decide |
|---|---|---|
| Syllogism | Two or three "all", "some" or "no" statements | Which conclusion must be true |
| Inference | A short rule and a fact | What follows, often using the reverse of the rule |
| Arrangement | Clues about seats, order or days | Who or what goes where |
| Assumption | A short argument | What the speaker takes for granted |
| Fallacy | A short argument | What is wrong with the reasoning |
| Argument strength | A question and several arguments | Which argument is strongest, or what weakens a claim |
| Cause and effect | A before-and-after situation | Which conclusion the evidence supports |

Some questions may allow more than one correct option. Read the instruction on each screen.

## A method that works

1. **Rewrite the statements in shorthand.** "All auditors are certified" becomes "A → C". "No drones allowed" becomes "D → not allowed".
2. **For syllogisms, test with a quick picture.** Draw two circles. If you can draw the facts in a way that makes an option false, that option does not have to be true.
3. **For "if" rules, remember the one safe reversal.** "If P then Q" lets you conclude "if not Q then not P". It does not let you conclude "if Q then P" or "if not P then not Q".
4. **For arrangements, place the fixed clues first.** Write the slots, fill in anything stated outright, then use the "next to" and "before" clues. Keep going until only one layout fits.
5. **For assumptions, use the denial test.** Flip the option to its opposite. If the argument falls apart, that option is an assumption it relies on.
6. **For argument strength, ask two questions.** Is it directly about the question asked? Does it rest on evidence rather than opinion, authority or fear of change?

## Traps that cost points

- **Converting "some".** "Some certified people are freelancers" does not mean any auditors are freelancers.
- **Affirming the result.** "If load is above 90%, the site slows. The site is slow." This does not prove the load is above 90%. Something else could slow the site.
- **Post hoc reasoning.** One event following another is not proof that the first caused the second.
- **Strong-sounding but irrelevant arguments.** An argument that quotes a famous person or a friend's company is weak unless it gives real evidence.
- **Stopping an arrangement early.** If two layouts still fit, you are not done. Most arrangement questions have exactly one layout that fits every clue.
- **Reading "best supported" as "proven".** Cause-and-effect questions often ask for the best supported conclusion. "Probably helped" can be right even though nothing is proven.

## Timing

Twelve minutes for an advanced test is tight. TestGorilla does not publish the number of questions. As guidance, syllogisms and "if" rules should take 30 to 40 seconds each, which leaves 60 to 90 seconds for arrangement questions. If an arrangement has not resolved after 90 seconds, choose the option that fits the clues you have used and move on.

## Practice items

These 3 items are original, written for these notes. They are not taken from TestGorilla or any publisher. Each has one correct answer.

**Item 1.** All auditors are certified. Some certified people are freelancers. Which statement must be true?

- A. Some auditors are freelancers.
- B. No auditors are freelancers.
- C. Some freelancers are certified.
- D. All freelancers are certified.

**Item 2.** "Our new manager started in March, and in April sales fell. The new manager caused the drop." What is the main flaw in this reasoning?

- A. It attacks the manager's character instead of the facts.
- B. It uses its conclusion as one of its reasons.
- C. It generalises from one manager to all managers.
- D. It assumes that because one event followed another, the first caused the second.

**Item 3.** Every time the server load goes above 90%, the website slows down. The website is not slow right now. Which statement must be true?

- A. The server load is below 50%.
- B. The server load is not above 90%.
- C. The server is offline.
- D. The website will slow down soon.

<details>
<summary>Answers and explanations, items 1 to 3</summary>

**Item 1: C.** "Some certified people are freelancers" means at least one person is both certified and a freelancer, so some freelancers are certified. *Why not A:* the freelancers who are certified might all be non-auditors. *Why not B:* equally, some auditors might be freelancers. We cannot tell.

**Item 2: D.** The only link given between the new manager and the drop is timing. That is the "after this, therefore because of this" flaw. *Why not A:* the argument does not criticise the manager's character. *Why not B:* the conclusion is not used as a reason.

**Item 3: B.** "If load above 90%, then slow." The site is not slow, so the load is not above 90%. This is the one safe reversal of an "if" rule. *Why not A:* the load could be 70% or 85%. We only know it is not above 90%.

</details>
